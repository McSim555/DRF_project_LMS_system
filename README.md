# Проект: Сервис управления платформой обучения

## Описание: создание приложения, управляющего обучающими материалами и курсами

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/DRF_project_LMS_system``
- Откройте проект online_learning_platform в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Запустите локальный сервер проекта ```online_learning_platform``` http://127.0.0.1:8000/

3. В домашнем задании 30.1:
   - создан Django-проект, подключен DRF в настройках проекта
   - созданы приложения ```materials```, ```users```
   - созданы модели пользователя, курса м урока
   - описан CRUD для моделей пользователя, курса и урока. Для реализации CRUD для пользователя и курса использован Viewsets, а для урока - Generic-классы.
   - для работы контроллеров описаны простейшие сериализаторы

3. В домашнем задании 30.2:
   - для модели курса добавлено в сериализатор поле вывода количества уроков. Поле реализовано с помощью SerializerMethodField()
   - добавлена новая модель Payment в приложение users
   - для сериализатора для модели курса реализовано поле вывода уроков
   - настроена фильтрация и сортировка для эндпоинта вывода списка платежей
   - для профиля пользователя сделан вывод истории платежей
